# مساعد حل الفيزياء

تطبيق ويب (PWA) يساعد الطالب على فهم حل مسائل الفيزياء خطوة بخطوة، بالاعتماد
على كتاب حلول موجود لديك.

## طريقة الاستخدام في التطبيق

1. الطالب يختار الفصل، ثم رقم السؤال.
2. يصوّر السؤال من الكتاب (اختياري) ليبقى أمامه أثناء الحل.
3. يظهر له الحل مقسّماً إلى خطوات: قبل كل خطوة يمكنه كتابة محاولته الخاصة،
   ثم يضغط لإظهار الخطوة الصحيحة، ويمكنه طلب توضيح إضافي إن لم يفهم.

## التشغيل محلياً

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`. يمكن "تثبيت" الصفحة على الشاشة الرئيسية للهاتف
كتطبيق PWA (Add to Home Screen).

## إضافة فصل جديد

بيانات كل فصل مخزّنة في `data/chapters/<رقم الفصل>.json` بالشكل التالي:

```json
{
  "id": 2,
  "titleAr": "اسم الفصل بالعربية",
  "subjectAr": "اسم الكتاب/المادة",
  "questions": [
    {
      "number": 1,
      "parts": [
        { "label": "أ", "steps": ["نص الخطوة الأولى", "نص الخطوة الثانية"] },
        { "label": null, "steps": ["يُستخدم label: null عندما لا يوجد تقسيم أ/ب/ج"] }
      ]
    }
  ]
}
```

ثم أضِف الفصل إلى `data/chapters/index.json`.

لأن كتاب الحل الحالي **بالعبرية**، عملية إضافة فصل جديد تكون كالتالي:
1. أرسل ملف PDF لحل الفصل الجديد.
2. تتم قراءة الصفحات كصور (وليس فقط كنص) لأن التخطيط غالباً بعمودين
   RTL، ما يجعل استخراج النص التلقائي عرضة للخطأ في ترتيب الأسئلة.
3. يُترجم المحتوى إلى العربية ويُنظّم حسب الشكل أعلاه، مع تقسيم كل جواب إلى
   خطوات تعليمية مناسبة (خصوصاً الأسئلة الحسابية التي فيها عدة أسطر اشتقاق).

## المساعدة الذكية الإضافية (اختياري)

زر "أحتاج توضيح أكثر" يستدعي `/api/explain`. إن لم يتوفر مفتاح API يظهر
نص بديل يطلب من الطالب تجربة تبسيط السؤال بنفسه. لتفعيل التوضيح الذكي:

```bash
# .env.local
ANTHROPIC_API_KEY=sk-ant-...
```

هذا لا يغيّر الحل نفسه (المأخوذ حرفياً من كتابك)، بل يستخدم فقط لإعادة شرح
الخطوة بأسلوب أبسط عند الحاجة.

## الحالة الحالية / خطوات لاحقة مقترحة

- الفصل 1 فقط مُدخل حالياً (9 أسئلة).
- التصوير حالياً مرجعي فقط (لا يوجد تحقق تلقائي أن الصورة تطابق السؤال
  المُختار) — يمكن إضافته لاحقاً عبر مطابقة الصورة بالذكاء الاصطناعي إذا رغبت.
- يمكن لاحقاً تحويل المشروع لتطبيق React Native/Flutter حقيقي إن احتجت نشراً
  على المتاجر، لكن نسخة الويب الحالية قابلة للتثبيت كتطبيق من المتصفح مباشرة.
